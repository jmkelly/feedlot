# Ran out of budget mid-redesign of Feedlot UI; had to revert CSS to keep app functional
Attempted a full Feedlot visual redesign (new CSS token system + new template classes + app.js scroll-read observer + new POST /articles/{id}/read Go endpoint) within a single 5m budget. Wrote new static/css/app.css first (the class-name contract), but reached the RESERVE phase before updating the 5 Go template string constants, app.js, the DB/handler/routes, and templates.go to match. A half-applied redesign leaves the UI broken (templates referenced removed utility classes), so I restored app.css to its original content and verified `go build` passes. Lesson: a coordinated multi-file frontend redesign across CSS+templates+JS+backend is too large for one 5m pass — either (a) delegate the self-contained CSS authoring to a sub-agent while doing endpoints, gate the whole change behind a branch, or (b) make the new CSS backwards-compatible by keeping old utility classes side-by-side so a partial rollout doesn't break rendering. Also: stage the redesign so each step leaves the app shippable.
