# Feedlot redesign direction: dark espresso chrome + linen reading pane + hay/brick accents; signature = livestock ear-tag unread badges
Subject world = feedlot (cattle). Avoided the default warm-cream+terracotta+serif look by splitting dark chrome (espresso near-black nav/sidebar) from a linen reading pane, using a characterful grotesk display (Bricolage Grotesque) + JetBrains Mono for field-ledger metadata, and making the signature element the livestock ear-tag unread badge (punched-hole plastic tag with stencil numerals). Accents: hay #D98E04 (primary) and brick #B23A1F (unread ribbon). Read/unread scroll-past feature delivered via IntersectionObserver in app.js + idempotent POST /articles/{id}/read endpoint + client-side localStorage toggle.
